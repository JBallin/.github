# .github

Shared GitHub configuration for [JBallin](https://github.com/JBallin) repositories.

This repository provides defaults for supported GitHub features when a repository does not define its own. The funding configuration links to JBallin's GitHub Sponsors profile.

See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for supported files and how inheritance works.
